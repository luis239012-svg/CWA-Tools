R on the remote display resets normal faults (status goes to 0:2). Star faults can only be cleared with "Reset at turbine". Built-in presets are the status codes found on Plouisy-T01 and T03 (SCADA event log, alarm list and the T01 and T03 status lists). Hover for the description. Descriptions and reset locks (*↑ nacelle, *↓ tower) come from the ENERCON CS82 status list V7.30 – type any code to look it up. Level 0 means the level was not recorded on these turbines. Add your own codes as extra presets.

Keys

↑ ↓ scroll menus, boards and values · → open a menu / next page (after the last page you return to the menu) · ← previous page · M back to the menu · E connect to the selected board / confirm · 4K end the RemoteDisplay session (then ← start again, → cancel back to the board list). R reset (counters on a counter page, otherwise the active fault – star faults need a reset at the turbine) · 2G = ↑ and ↓ pressed together: clears the counters on a counter page, on the board-select page jumps to the I/O board, anywhere else returns to general data.
Keyboard: arrows, M, E/Enter, R, K (4K), G or ↑+↓ together (2G).

Changing a parameter

Press E on any page with a setting: Pxxxx= parameters on the controller, and on a connected board any value or ON/OFF in its sub-menus (blade, yaw, excitation, rectifier, I/O boards…). The first time you are asked for service access: user number, then service code (↓ raises a digit, ↑ lowers it, E confirms each digit). You can also unlock in advance on the service code page in special functions. Then ↑↓ change the value, E saves, M or R cancels. Live measured values are read-only. Changes stay in this simulator; the exact edit key sequence on the real controller is approximated.
